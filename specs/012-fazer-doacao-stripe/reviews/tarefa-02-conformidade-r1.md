# AJUSTES NECESSÁRIOS

1. **[P2] Os testes de 503 não demonstram que os IDs retornados correspondem a registros duráveis.** O teste HTTP usa um repositório falso que gera IDs aleatórios; ele verifica status, corpo e chamadas, mas passaria mesmo sem persistência real. O teste com PostgreSQL cobre o valor acima do limite do Stripe, não a resposta 503 bruta. Evidência: [donations.create.e2e-spec.ts](/home/nico/Documentos/ChatGPT/Contabilidade/motor-calculo-icms-atividade-09/apps/api/test/donations.create.e2e-spec.ts:52) e [donations.create.db-spec.ts](/home/nico/Documentos/ChatGPT/Contabilidade/motor-calculo-icms-atividade-09/apps/api/test/donations.create.db-spec.ts:35). O código executa e aguarda a transação de `createIntent` antes de chamar o gateway ([create-donation.ts](/home/nico/Documentos/ChatGPT/Contabilidade/motor-calculo-icms-atividade-09/apps/api/src/donations/application/create-donation.ts:94)), mas essa garantia não é integrada ao teste de 503.

2. **[P3] Falta um caso explícito de corpo JSON malformado na cobertura de HTTP 503.** Os casos testados são envelope de erro, HTML, JSON sem `error` e corpo vazio; nenhum envia JSON inválido com `Content-Type: application/json`. Evidência: [donations.create.e2e-spec.ts](/home/nico/Documentos/ChatGPT/Contabilidade/motor-calculo-icms-atividade-09/apps/api/test/donations.create.e2e-spec.ts:78). A implementação preserva o status 503 quando a leitura do corpo falha ([stripe-client.ts](/home/nico/Documentos/ChatGPT/Contabilidade/motor-calculo-icms-atividade-09/apps/api/src/donations/adapters/stripe/stripe-client.ts:26)), mas essa borda não está especificada por um teste dedicado.

**Conferência estática:** os ajustes arquivados foram atendidos no código consultado: validação das chaves do corpo original, HMAC para a identidade da operação, armazenamento sem limite local de 63 dígitos e preservação do status 503 antes de interpretar o corpo. O fluxo mantém o pedido antes do envio ao Stripe; erros de validação não persistem nem chamam o gateway; configuração ausente/de produção e falha do banco antes da intenção não chegam ao Stripe. Não executei testes nem alterei arquivos.
